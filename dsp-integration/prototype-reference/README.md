# Prototype reference (read-only)

The latest prototype source for Display Types & DSP Integration. It matches
the published prototype: https://claude.ai/artifact/2cc25ZNLFP5AtQk2KmeY98

Use it as the UI specification and for model shapes (src/model/sellside.js:
targeting variables, example values, DSP credential fields). Do not edit it
and do not ship it: rebuild the screens in the POC app.

Run it locally: npm install && npm run dev
